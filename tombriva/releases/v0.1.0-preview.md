# Tombriva VR 0.1.0 — source preview

An experimental spatial browser for watching compatible 360° and VR180 web video on **PSVR2 on a Windows PC through SteamVR**, built on Firefox ESR 153.2.0 with adaptations informed by Firefox Reality PC.

> **Source only.** This release has no installer, no executable and no update channel. It is meant for developers who can build Gecko on Windows. Tombriva VR is an independent project and is not affiliated with or endorsed by Mozilla, Valve, Sony or Google/YouTube.

## Highlights

- Browser panel in the SteamVR dashboard, or detached into the room as a free window with drag controls.
- Compatible 360° and VR180 playback from the page's own video element, with ERP, validated EAC layouts and supported VR180 metadata/mesh handling.
- PSVR2 Sense controls: point and click on the panel, trigger to recenter, R1/grip to return to the browser.
- One-time onboarding in English and Brazilian Portuguese.
- Configurable start page (`vulpis.startup.homepage`, default Google).

## Known limitations

- **No locomotion in SteamVR Home while the detached window is open.** The interactive detached panel takes over controller input, so the analog stick does not move you in Home. Workaround to try: dock the browser, close the dashboard, move, then reopen. A proper fix is planned for V2 ([study](https://github.com/Rafaelgarra/tombriva-vr/blob/tombriva-v0.1.0-preview/tombriva/INPUT_COEXISTENCE_V2.md)).
- Tested only on the maintainer's PSVR2 setup; other GPUs, headsets, sites and media formats are unverified.
- The executable is still built as `firefox.exe` and some inherited Firefox/Nightly surfaces are not rebranded yet. Do not redistribute builds as Firefox.
- Not a replacement for a maintained general-purpose browser for sensitive browsing: permission-testing preferences and GPU sandbox settings still need a security review.

## Requirements

Windows x64, a GPU/driver that can decode the chosen video, a working PSVR2 PC setup (Steam, SteamVR and the PlayStation VR2 App, installed separately) and paired Sense controllers.

## Build

Follow [tombriva/BUILD.md](https://github.com/Rafaelgarra/tombriva-vr/blob/tombriva-v0.1.0-preview/tombriva/BUILD.md). In short: MozillaBuild + Visual Studio toolchain from `mach bootstrap`, the documented `.mozconfig` (`--enable-fxr-desktop`, updater disabled), `./mach build`, then launch with `--fxr -no-remote -profile <dedicated-profile>`.

Clone with a shallow history if you do not need upstream Firefox history:

```sh
git clone --depth 1 --branch tombriva-v0.1.0-preview https://github.com/Rafaelgarra/tombriva-vr.git
```
